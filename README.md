# 投币音乐

使用 **Go + Vue3** 开发的自部署音乐播放网站,电脑浏览器与手机浏览器均可使用。

## 特性

- 🔍 **多源聚合搜索**:酷我 / QQ / 网易 / 酷狗 / 咪咕 五个音源,支持 **歌曲 / 专辑 / 歌单 / 歌手 / 歌词** 分类搜索(各源按实际支持情况展示)
- 🎵 **采集接口(自定义音源协议)**:在 `config.yaml` 中配置音源脚本 URL,后端用 goja 运行脚本解析播放地址,支持 128K~Hi-Res 多音质、失败自动降级;可在「系统设置」页在线更换并热重载
- 🔥 **热门榜单**:网易云官方榜(飙升榜/新歌榜/热歌榜等 60+),点击进入榜单曲目
- 🎲 **随机歌单**:一键生成 100 首随机歌曲,列表循环从第一首开始播放
- 💿 **专辑/歌单/歌手详情页**,一键播放全部
- 🎚️ **完整播放器**:歌词滚动高亮(含翻译)、封面、**随音乐跳动的频谱背景条**(Web Audio)、播放队列、单曲循环/列表循环/随机、进度/音量、MediaSession 锁屏控制
- ❤️ **收藏歌单**:多歌单管理(创建/重命名/删除),收藏时可选择目标歌单,不选则进默认歌单,歌单内可搜索
- 🚫 **拉黑歌曲**:播放自动跳过,搜索结果置灰标记,可搜索/取消拉黑
- 🕘 **播放历史**:按用户保存,可搜索/重播/清空
- 👤 **用户系统**:注册/登录仅需用户名+密码,未登录全屏遮罩;支持**修改密码**;内置超级管理员 `admin / 123456`(首个注册用户为普通用户,登录后请立即改密)
- 🛡️ **超管功能**:用户列表(删除用户会级联删除其收藏/拉黑/历史)、系统设置(采集接口 + 前台注册开关)
- 📱 **响应式 UI**:桌面顶栏(首页/热门/随机/收藏 + 我的下拉)/ 移动端底部 Tab + 我的页,深色/浅色主题,全套统一线性图标
- 🔊 音频经后端代理流式转发,解决防盗链与跨域

## 快速开始

### 运行

```
tbmusic.exe            # Windows 单文件,开箱即用
./tbmusic              # Linux/macOS
```

启动后控制台会打印本机与局域网地址,手机浏览器扫码/输入局域网地址即可访问。

### 从源码构建

依赖:Go 1.27.3+、Node.js 20.19+ 或 22.12+。本项目使用 fnm 的 Node.js 26.13.0（见 `.node-version`）；进入项目后执行 `fnm use`。

```bash
# 构建前端
cd web && npm ci && npm run build && cd ..

# 构建后端(前端产物通过 go:embed 打进单文件)
go build -o tbmusic.exe .
```

仓库不包含依赖目录、构建产物和本地运行数据。首次构建或清理后，必须先执行上述前端构建，再运行 `go build`、`go run .` 或 `go test ./...`，以满足 `go:embed` 对 `web/dist` 的要求。本地 `config.yaml` 和 `data/` 已加入 `.gitignore`，配置模板见 `config.example.yaml`。

开发模式:完成一次前端构建后，终端 1 运行 `go run .`,终端 2 在 `web/` 下 `npm run dev`(Vite 5173 端口,已配置 /api 代理)。

「个人设置」底部显示当前前端版本与构建时间，版本号来自 `web/package.json`。每次 `npm run build` 会生成独立构建标识和 `dist/version.json`；页面打开、回到前台时及前台每 60 秒检查更新，检测到不同构建后显示「系统已更新」，点击「刷新页面」才更新页面。「稍后更新」可暂时收起提示，个人设置中仍可刷新。未修改版本号的重新构建也能被检测到；断网或部署期间检查失败不会自动刷新。播放连接记录可在「外观与播放」下方刷新或清空，清空后下次播放会重新判断直连兼容性。

## 配置(config.yaml)

```yaml
server:
  addr: "0.0.0.0:8080"

# 采集接口(自定义音源脚本),依序优先,可配多个
source:
  timeout: 15s
  scripts: [] # 不预置音源地址，请在系统设置中自行添加

database:
  path: "./data/tbmusic.db"   # SQLite,首次运行自动建库建表
session:
  days: 30                 # 登录会话有效期
auth:
  allowRegister: true      # 前台注册开关(系统设置页可在线改)
cache:
  sizeMB: 3072             # 缓存空间上限(MB),系统设置可在线调整
  urlTTL: 20m              # 播放地址缓存时长
  searchTTL: 10m           # 搜索结果(含页码、类型、音源)
  detailTTL: 30m           # 外部歌单、专辑、歌手详情与榜单
  lyricTTL: 24h
  coverTTL: 168h           # 封面地址与图片文件
```

超级管理员默认账户 `admin / 123456`,启动时自动创建,登录后请在「个人设置」中修改密码。采集接口也可由超管在网页「系统设置」中在线更换(写回 config.yaml 并热重载,失败自动保留旧脚本)。

## 架构

```
├── main.go                    # 启动入口:配置/数据库/脚本加载/静态托管
├── internal/
│   ├── lxsource/              # 自定义音源协议宿主(goja + 事件循环)
│   │   ├── manager.go         # 脚本下载/inited 握手/musicUrl 调用/Promise 等待
│   │   ├── env.go             # globalThis.lx 环境:on/send/request/utils(buffer/crypto/zlib)
│   │   └── pool.go            # 多音源池与热重载
│   ├── music/                 # 内置音源(搜索/详情/歌词/封面,与 lx-music 字段兼容)
│   │   ├── kw/ tx/ wy/ kg/ mg/
│   │   └── types.go, httpx.go
│   ├── server/                # HTTP:auth/search/detail/music-url/stream/playlists...
│   ├── store/                 # SQLite:users/sessions/playlists/blacklist/history
│   ├── config/                # yaml 配置
│   └── cache/                 # 持久化 LFU 缓存(支持 TTL 和容量限制)
└── web/                       # Vue3 + TS + Vite + Pinia 前端
```

播放链路:`浏览器 → /api/music-url(优先命中地址缓存) → 音源直连`。直连报错或等待超过 7 秒时自动使用 `/api/stream` 中转，尽量保留播放位置。下载仍走带文件名的流式中转，不缓存音频文件。

直连兼容记录按「音源 + 实际音频域名」保存在当前浏览器：直连成功记录 7 天；直连失败且中转成功才记录为使用中转，24 小时后重新尝试。浏览器禁止自动播放或两条路径都失败，不会误判音源不兼容。「个人设置」可查看记录，播放页显示当前连接方式。为兼容未开放 CORS 的音源，直连音频使用独立播放器，不进入频谱分析链；频谱在中转播放时随音乐变化。

播放地址、搜索、外部歌单/榜单、歌词、封面地址和封面图片共用磁盘缓存，默认上限 **3072 MB (3 GiB)**。在「系统设置 → 资源缓存」输入整数 MB 即可调整大小，立即生效并写回 `cache.sizeMB`，重启后保留；范围为 1–1048576 MB，1 MB = 1024² 字节。调小容量会立即清理超出部分。默认目录是数据库同目录下的 `cache/`，可通过 `cache.dir` 指定专用目录。容量计算包含缓存文件头和数据；写入前先清理过期条目，再淘汰命中次数最少的条目，次数相同时优先淘汰最久未访问的条目。数据与条目命中次数在重启后保留；缓存空间上限不预分配。仅成功响应进入缓存，重复的搜索/详情/歌词/封面请求合并回源。音频流不写入该缓存，用户收藏歌单与黑名单继续直接读写数据库。可在该模块刷新统计或直接点击「清空缓存」，清空会删除已有资源缓存、重置统计并阻止清空前已开始的加载回填缓存，后续新请求正常建立缓存。统计从本次启动或最近一次清空起计算。

## 主要 API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/auth/register、/api/auth/login、/api/auth/logout | 账号(仅用户名+密码) |
| GET | /api/sources | 脚本状态 + 各源能力(分类/音质) |
| GET | /api/search?source=&type=&keyword=&page= | 五类搜索 |
| GET | /api/detail?type=album/songlist/artist&source=&id= | 详情曲目 |
| POST | /api/music-url | 取播放地址(自动音质降级) |
| POST | /api/lyric、/api/pic | 歌词 / 封面 |
| GET | /api/stream?url=&source= | 音频代理(Range 支持) |
| GET | /api/random-song | 随机一首 |
| CRUD | /api/playlists、/api/blacklist、/api/history | 收藏 / 拉黑 / 历史 |
| GET/PUT | /api/source-status | 采集接口状态(管理员可热更新) |
